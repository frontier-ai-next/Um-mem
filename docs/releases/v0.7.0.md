# UM-MEM v0.7.0

UM-MEM now ships its Go runtime as a public GitHub release. The runtime, command-line tools, MCP server, local service and lifecycle hooks are built from the latest Go implementation, including the scoped recall and embedded-catalog packaging repairs.

## Included

- Durable canonical SQLite memory with workspace and profile isolation, provenance and governed lifecycle operations.
- Native Mnemosyne, MemPalace, Hindsight and Zvec integrations, with explicit health checks for the selected backend.
- Codex, Claude Code and Hermes configuration and lifecycle hooks; an optional OpenCode TypeScript adapter and a local memory panel.
- Four Go executables for Linux, macOS and Windows on amd64 and arm64, plus a standalone npm launcher archive.
- SHA-256 verification before an installed binary set is activated. Failed installation preserves the previously active version.

## Install

Node.js 18 or newer is required for the launchers. OpenCode requires Node.js 24 or newer.

```console
npm install -g https://github.com/frontier-ai-next/Um-mem/releases/download/v0.7.0/um-mem-cli-0.7.0.tgz
um-memory install
um-memory health --repo-root /absolute/path/to/memory-store --workspace my-project --profile default --backend mnemosyne
```

Public release downloads need no GitLab access token and no Go compiler. The selected backend may require its own model assets or external service.

## Upgrade from v0.6.0

This release replaces the previous Python Lethyx package with the Go runtime; Python imports and old launch commands are not a drop-in interface. Use the new CLI, Go module or MCP connection described in the installation guide.

Back up an existing store and verify a copy with its original workspace, profile and backend before permitting writes. Check `health`, `reconcile --dry-run`, write, recall, correction and retraction on the copy. The release does not automatically migrate native data between backends.

## Verification

The release workflow runs Go tests and vet with and without `purego`, npm source installation, OpenCode native Mnemosyne journeys, panel tests and a secret scan before it builds and publishes the platform assets. Every asset is listed in `SHA256SUMS`.
