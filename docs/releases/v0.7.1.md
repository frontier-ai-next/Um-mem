# UM-MEM v0.7.1

This release adds the DeepSeek Harness integration and improves source-aware focus, retrieval and the local memory atlas.

- Harness uses per-turn active masks for automatic context and keeps explicit recall available for additional evidence. Current, source-backed notes in the same topic take precedence over interim agent notes. Raw confirmation remains usable when the agent has not written a note.
- The compact adapter carries original quotes across revisions, preserves links to the sources, and updates search tags and author-supplied facets. Hosts can attach verifiable references from allowlisted tool results.
- The optional evaluation bundle checks artifacts against visible sources, validates exact dates, batches tests and detects when malformed rows abort a normal JSON batch.
- The atlas exposes topic and record relationships, revision history, metadata and the context delivered to Harness.
- MemPalace uses the supplied vectors without initializing a second embedding runtime in Chroma.

## Installation

```console
npm install -g https://github.com/frontier-ai-next/Um-mem/releases/download/v0.7.1/um-mem-cli-0.7.1.tgz
um-memory install
```

See [Harness setup](../../integrations/dsh/README.md) for the optional host integration. Keep the existing workspace, profile and backend when upgrading a store.

The release workflow publishes the tagged build from `main` after its verification jobs pass. The archive and binaries ship with `SHA256SUMS`.
